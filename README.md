# QuickNotes App

A clean, responsive, and persistent note-taking web application built with vanilla HTML5, CSS3, and modern JavaScript.

## Description
QuickNotes allows users to capture quick ideas, organize them into customizable categories (Personal, Work, Study), search through existing notes in real-time, and securely store everything locally in the browser using `localStorage`.

## Features
- **Categorized Notes:** Tag notes as Personal, Work, or Study with distinct color-coded left borders.
- **Input Validation:** Instant feedback if notes are empty or exceed the 200-character limit.
- **Live Search:** Filter your note list instantly as you type.
- **Persistent Storage:** Notes survive page refreshes and browser restarts via browser `localStorage`.
- **Fully Responsive:** Adapts seamlessly from desktop to mobile screens using Flexbox and media queries.
